# Matchday

Pick your teams across football, NBA, NFL, NHL, MLB, F1 and cricket. Every upcoming game lands in one timeline sorted by start time, shown in the viewer's own timezone, with reminders.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests
npm run smoke      # live check of the ESPN / Jolpica data layer
npm run teams      # rebuild public/teams.json (every few months)
npm run build      # static site in dist/ — host anywhere (Vercel, Netlify, Cloudflare Pages)
```

## How it works
- **No backend for the site.** Schedules come straight from ESPN's public JSON (NBA/NFL/NHL/MLB/football/cricket) and Jolpica (F1), fetched in the browser and cached in localStorage. Teams you follow live in localStorage too.
- **`public/teams.json`** is generated by `scripts/build-teams.mjs` because ESPN's team lists send no CORS headers.
- ESPN's API is unofficial and undocumented. It can change without notice; `npm run smoke` is the quick way to check it still works.

## Alerts (honest version)
| Channel | Works when | Needs |
|---|---|---|
| Browser | tab or installed PWA is open | nothing |
| Phone push (ntfy) | always — ntfy's server holds the message | free ntfy app; queues the next 3 days each time you open the site |
| Email | always | `worker/` deployed (Cloudflare free + Resend free) |

Email setup: see `worker/wrangler.toml`. Create a KV namespace, set `SITE_URL`/`API_URL`, `npx wrangler secret put RESEND_API_KEY`, `npx wrangler deploy`, then build the site with `VITE_API_URL=<worker url>`.
Resend only lets you send to your own address until you verify a domain. The Cloudflare free plan allows 50 outbound requests per cron run, which is fine for a handful of teams.
